# Guidelines de Contribución

Gracias por contribuir a este proyecto.

## Flujo de trabajo
1. Crear una rama a partir de la última versión de `main`
2. Realizar cambios específicos y claros
3. Hacer commits descriptivos
4. Crear un Pull Request hacia `main`

## Convenciones
- Usar nombres descriptivos para ramas
- No hacer commits directamente a `main`
- Mantener el proyecto funcional antes de hacer merge
